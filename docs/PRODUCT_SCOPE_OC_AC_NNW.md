# OC.Documenty.pl — zakres produktu

Portal obejmuje trzy główne produkty komunikacyjne:

- **OC** — obowiązkowe ubezpieczenie odpowiedzialności cywilnej; główny obszar dokumentów, wypowiedzeń i zmiany ubezpieczyciela.
- **AC** — dobrowolna ochrona własnego pojazdu; porównanie zakresu, udziału własnego, wariantu naprawy i wyłączeń.
- **NNW** — dobrowolna ochrona kierowcy i pasażerów; porównanie sumy ubezpieczenia i zakresu świadczeń.

## Główny lejek

1. Użytkownik wskazuje problem lub termin odnowienia.
2. Porównuje pakiety OC / AC / NNW w sekcji partnerskiej.
3. Kupuje nową polisę z zachowaniem ciągłości obowiązkowego OC.
4. Przygotowuje właściwe wypowiedzenie starego OC.
5. Podpisuje dokument, wysyła go i zachowuje potwierdzenie.

## Zasady komunikacji

- Nie sugerować, że AC lub NNW są obowiązkowe.
- Nie przedstawiać przykładowych oszczędności jako gwarantowanych.
- Wyraźnie oznaczać sekcje afiliacyjne.
- Porównywać nie tylko cenę, ale również zakres, udział własny, wyłączenia i sumy ubezpieczenia.
